How it works

A gradient-boosting model learns weekly counts for every neighbourhood and crime type from 2003 onward: recent weeks, the same season last year, and long-run trends. Totals add up the neighbourhood forecasts. It predicts how many incidents a week, never where or when a specific one will happen.

How accurate it is

Trained on data up to 2024, then tested on 2025–2026, which it never saw. Lower is better; the best per row is marked.

Limits

It only knows recorded crime, which depends on reporting and policing as well as crime itself. The latest weeks are left out until late reports arrive. City-wide ranges are cautious: 95% of test weeks fell inside them.
